# OpenTelemetry (`opentelemetry`)

- **Category:** Analytics & Monitoring
- **Kong documentation:** [https://developer.konghq.com/plugins/opentelemetry/](https://developer.konghq.com/plugins/opentelemetry/)
- **Targets:** `kong-3.9`, `kong-gateway-3.14`
- **Scopes:** `global`, `service`, `route`, `consumer`
- **Protocols:** `grpc`, `grpcs`, `http`, `https`, `tcp`, `tls`, `tls_passthrough`, `udp`, `ws`, `wss`

## Example

```ts
import { Kong } from 'kong-api-client';

const kong = new Kong({ adminUrl: 'http://localhost:8001' });

await kong.plugins.enable('opentelemetry', {
  on: { route: 'my-route' },
  config: {
    traces_endpoint: 'https://otel.example.com/v1/traces',
    resource_attributes: { 'service.name': 'api-gateway' },
  },
});
```
