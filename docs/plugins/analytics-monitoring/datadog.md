# Datadog (`datadog`)

- **Category:** Analytics & Monitoring
- **Kong documentation:** [https://developer.konghq.com/plugins/datadog/](https://developer.konghq.com/plugins/datadog/)
- **Targets:** `kong-3.9`, `kong-gateway-3.14`
- **Scopes:** `global`, `service`, `route`, `consumer`
- **Protocols:** `grpc`, `grpcs`, `http`, `https`, `tcp`, `tls`, `tls_passthrough`, `udp`, `ws`, `wss`

## Example

```ts
import { Kong } from 'kong-api-client';

const kong = new Kong({ adminUrl: 'http://localhost:8001' });

await kong.plugins.enable('datadog', {
  on: { route: 'my-route' },
  config: { host: '10.0.0.10', port: 8125, prefix: 'kong' },
});
```

## Configuration fields

| Field                           | Type                                                                                                        | Required | Default         | Description                                                                                                                                                                                                                                      |
| ------------------------------- | ----------------------------------------------------------------------------------------------------------- | -------- | --------------- | ------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------ |
| `consumer_tag`                  | `string`                                                                                                    | No       | `'consumer'`    | String to be attached as tag of the consumer.                                                                                                                                                                                                    |
| `flush_timeout`                 | `number`                                                                                                    | No       | —               | Optional time in seconds. If `queue_size` > 1, this is the max idle time before sending a log with less than `queue_size` records. Deprecated: datadog: config.flush_timeout is deprecated, please use config.queue.max_coalescing_delay instead |
| `host`                          | `string`                                                                                                    | No       | `'localhost'`   | A string representing a host name, such as example.com.                                                                                                                                                                                          |
| `metrics`                       | `Array<object>`                                                                                             | No       | 6 default items | List of metrics to be logged.                                                                                                                                                                                                                    |
| `metrics[].consumer_identifier` | `'consumer_id' \| 'custom_id' \| 'username'`                                                                | No       | —               | Authenticated user detail                                                                                                                                                                                                                        |
| `metrics[].name`                | `'kong_latency' \| 'latency' \| 'request_count' \| 'request_size' \| 'response_size' \| 'upstream_latency'` | Yes      | —               | Datadog metric’s name                                                                                                                                                                                                                            |

| `metrics[].stat_type`           | `'counter' \| 'distribution' \| 'gauge' \| 'histogram' \| 'meter' \| 'set' \| 'timer'`                      | Yes      | —               | Determines what sort of event the metric represents                                                                                                                                                                                              |
| `metrics[].tags`                | `Array<string>`                                                                                             | No       | —               | List of tags                                                                                                                                                                                                                                     |
| `port`                          | `number`                                                                                                    | No       | `8125`          | An integer representing a port number between 0 and 65535, inclusive.                                                                                                                                                                            |
| `prefix`                        | `string`                                                                                                    | No       | `'kong'`        | String to be attached as a prefix to a metric's name.                                                                                                                                                                                            |

| `queue_size`                    | `number`                                                                                                    | No       | —               | Maximum number of log entries to be sent on each message to the upstream server. Deprecated: datadog: config.queue_size is deprecated, please use config.queue.max_batch_size instead                                                            |
| `retry_count`                   | `number`                                                                                                    | No       | —               | Number of times to retry when sending data to the upstream server.
