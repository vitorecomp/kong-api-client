# ACME (`acme`)

- **Category:** Security
- **Kong documentation:** [https://developer.konghq.com/plugins/acme/](https://developer.konghq.com/plugins/acme/)
- **Targets:** `kong-3.9`, `kong-gateway-3.14`
- **Scopes:** `global`
- **Protocols:** `grpc`, `grpcs`, `http`, `https`

## Example

```ts
import { Kong } from 'kong-api-client';

const kong = new Kong({ adminUrl: 'http://localhost:8001' });

await kong.plugins.enable('acme', {
  config: {
    account_email: 'ops@example.com',
    domains: ['api.example.com'],
    storage: 'shm',
    tos_accepted: true,
  },
});
```
