# Basic Auth (`basic-auth`)

- **Category:** Authentication
- **Kong documentation:** [https://developer.konghq.com/plugins/basic-auth/](https://developer.konghq.com/plugins/basic-auth/)
- **Targets:** `kong-3.9`, `kong-gateway-3.14`
- **Scopes:** `global`, `service`, `route`
- **Protocols:** `grpc`, `grpcs`, `http`, `https`, `ws`, `wss`

## Example

```ts
import { Kong } from 'kong-api-client';

const kong = new Kong({ adminUrl: 'http://localhost:8001' });

await kong.plugins.enable('basic-auth', {
  on: { route: 'my-route' },
  config: { hide_credentials: true, realm: 'api' },
});
```
