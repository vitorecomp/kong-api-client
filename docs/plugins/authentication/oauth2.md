# OAuth 2.0 Authentication (`oauth2`)

- **Category:** Authentication
- **Kong documentation:** [https://developer.konghq.com/plugins/oauth2/](https://developer.konghq.com/plugins/oauth2/)
- **Targets:** `kong-3.9`, `kong-gateway-3.14`
- **Scopes:** `global`, `service`, `route`
- **Protocols:** `grpc`, `grpcs`, `http`, `https`, `ws`, `wss`

## Example

```ts
import { Kong } from 'kong-api-client';

const kong = new Kong({ adminUrl: 'http://localhost:8001' });

await kong.plugins.enable('oauth2', {
  on: { route: 'my-route' },
  config: {
    scopes: ['read', 'write'],
    mandatory_scope: true,
    enable_client_credentials: true,
    token_expiration: 7200,
  },
});
```

## Configuration fields

| Field                               | Type                          | Required | Default                                      | Description                                                                                                                                                                                           |
| ----------------------------------- | ----------------------------- | -------- | -------------------------------------------- | ----------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| `accept_http_if_already_terminated` | `boolean`                     | No       | `false`                                      | Accepts HTTPs requests that have already been terminated by a proxy or load balancer.                                                                                                                 |
| `anonymous`                         | `string`                      | No       | —                                            | An optional string (consumer UUID or username) value to use as an “anonymous” consumer if authentication fails.                                                                                       |
| `auth_header_name`                  | `string`                      | No       | `'authorization'`                            | The name of the header that is supposed to carry the access token.                                                                                                                                    |
| `enable_authorization_code`         | `boolean`                     | No       | `false`                                      | An optional boolean value to enable the three-legged Authorization Code flow (RFC 6742 Section 4.1).                                                                                                  |
| `enable_client_credentials`         | `boolean`                     | No       | `false`                                      | An optional boolean value to enable the Client Credentials Grant flow (RFC 6742 Section 4.4).                                                                                                         |
| `enable_implicit_grant`             | `boolean`                     | No       | `false`                                      | An optional boolean value to enable the Implicit Grant flow which allows to provision a token as a result of the authorization process (RFC 6742 Section 4.2).                                        |
| `enable_password_grant`             | `boolean`                     | No       | `false`                                      | An optional boolean value to enable the Resource Owner Password Credentials Grant flow (RFC 6742 Section 4.3).                                                                                        |
| `global_credentials`                | `boolean`                     | No       | `false`                                      | An optional boolean value that allows using the same OAuth credentials generated by the plugin with any other service whose OAuth 2.0 plugin configuration also has `config.global_credentials=true`. |
| `hide_credentials`                  | `boolean`                     | No       | Kong 3.9: `false`; Kong Gateway 3.14: `true` | An optional boolean value telling the plugin to show or hide the credential from the upstream service.                                                                                                |
| `mandatory_scope`                   | `boolean`                     | No       | `false`                                      | An optional boolean value telling the plugin to require at least one `scope` to be authorized by the end user.                                                                                        |
| `pkce`                              | `'lax' \| 'none' \| 'strict'` | No       | `'lax'`                                      | Specifies a mode of how the Proof Key for Code Exchange (PKCE) should be handled by the plugin.                                                                                                       |
| `provision_key`                     | `string`                      | No       | —                                            | The unique key the plugin has generated when it has been added to the Service.                                                                                                                        |
| `realm`                             | `string`                      | No       | —                                            | When authentication fails the plugin sends `WWW-Authenticate` header with `realm` attribute value.                                                                                                    |
| `refresh_token_ttl`                 | `number`                      | No       | `1209600`                                    | Time-to-live value for data                                                                                                                                                                           |
| `reuse_refresh_token`               | `boolean`                     | No       | `false`                                      | An optional boolean value that indicates whether an OAuth refresh token is reused when refreshing an access token.                                                                                    |
| `scopes`                            | `Array<string>`               | No       | —                                            | Describes an array of scope names that will be available to the end user. If `mandatory_scope` is set to `true`, then `scopes` are required.                                                          |
| `token_expiration`                  | `number`                      | No       | `7200`                                       | An optional integer value telling the plugin how many seconds a token should last, after which the client will need to refresh the token. Set to `0` to disable the expiration.                       |
| `persistent_refresh_token`          | `boolean`                     | No       | `false`                                      | Kong Gateway 3.14 only.                                                                                                                                                                               |
