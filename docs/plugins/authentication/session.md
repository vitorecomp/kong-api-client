# Session (`session`)

- **Category:** Authentication
- **Kong documentation:** [https://developer.konghq.com/plugins/session/](https://developer.konghq.com/plugins/session/)
- **Targets:** `kong-3.9`, `kong-gateway-3.14`
- **Scopes:** `global`, `service`, `route`
- **Protocols:** `grpc`, `grpcs`, `http`, `https`, `tcp`, `tls`, `tls_passthrough`, `udp`, `ws`, `wss`

## Example

```ts
import { Kong } from 'kong-api-client';

const kong = new Kong({ adminUrl: 'http://localhost:8001' });

await kong.plugins.enable('session', {
  on: { route: 'my-route' },
  config: {
    storage: 'cookie',
    cookie_name: 'app_session',
    cookie_same_site: 'Lax',
    idling_timeout: 900,
  },
});
```
