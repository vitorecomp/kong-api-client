# Rate Limiting (`rate-limiting`)

- **Category:** Traffic Control
- **Kong documentation:** [https://developer.konghq.com/plugins/rate-limiting/](https://developer.konghq.com/plugins/rate-limiting/)
- **Targets:** `kong-3.9`, `kong-gateway-3.14`
- **Scopes:** `global`, `service`, `route`, `consumer`
- **Protocols:** `grpc`, `grpcs`, `http`, `https`

## Example

```ts
import { Kong } from 'kong-api-client';

const kong = new Kong({ adminUrl: 'http://localhost:8001' });

await kong.plugins.enable('rate-limiting', {
  on: { route: 'my-route' },
  config: { minute: 100 },
});
```
