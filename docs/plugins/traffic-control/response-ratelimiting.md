# Response Rate Limiting (`response-ratelimiting`)

- **Category:** Traffic Control
- **Kong documentation:** [https://developer.konghq.com/plugins/response-ratelimiting/](https://developer.konghq.com/plugins/response-ratelimiting/)
- **Targets:** `kong-3.9`, `kong-gateway-3.14`
- **Scopes:** `global`, `service`, `route`, `consumer`
- **Protocols:** `grpc`, `grpcs`, `http`, `https`

## Example

```ts
import { Kong } from 'kong-api-client';

const kong = new Kong({ adminUrl: 'http://localhost:8001' });

await kong.plugins.enable('response-ratelimiting', {
  on: { route: 'my-route' },
  config: { limits: { requests: { minute: 100 } }, header_name: 'X-Kong-Limit', policy: 'local' },
});
```
